# A股智能预测系统 — 因子设计文档

## 概述

从现有4因子(趋势/动量/位置/量价)扩展为4维度18因子。每个因子独立计算、独立打分(±范围)，最终按维度聚合后加权求和。

## 一、技术面因子 (7因子，维度权重 35%)

### 1.1 均线趋势 (权重 1.5 → ±3.5)
- **计算**: `(close - MA5) / MA5 * 100`，连续评分而非离散
- **数据源**: DuckDB daily_adj.close
- **逻辑**: MA5/MA10多空排列 × 偏离度，越偏离信号越强
- **初始权重**: 1.5 (牛市) / 0.8 (震荡) / 1.2 (熊市)

### 1.2 5日动量 (权重 1.0 → ±4.0)
- **计算**: `SUM(pct_chg[-5:])` × 0.2
- **数据源**: DuckDB daily_adj.pct_chg
- **逻辑**: 连续评分，5日累计涨幅越高动量越强
- **初始权重**: 1.0

### 1.3 10日位置 (权重 0.5 → ±1.0)
- **计算**: `(close - low_10d) / (high_10d - low_10d) * 100`
- **数据源**: DuckDB daily_adj.high/low
- **逻辑**: 0-100连续映射到-1~+1
- **初始权重**: 0.5

### 1.4 量价配合 (权重 0.5 → ±1.5)
- **计算**: `IF vol_ratio>1.3 THEN chg_1d*0.15 ELSE 0`
- **数据源**: DuckDB daily_adj.vol + pct_chg
- **逻辑**: 放量时根据方向加分，缩量时中性
- **初始权重**: 0.5

### 1.5 ATR波动率 [新增] (权重 0.5 → ±1.0)
- **计算**: 14日True Range均值 / close * 100
- **数据源**: DuckDB daily_adj.high/low/close
- **逻辑**: ATR过高(>5%)=高风险衰减，ATR适中(2-4%)=波动可交易
- **初始权重**: 0.5

### 1.6 筹码分布 [新增] (权重 0.3 → ±0.8)
- **计算**: 60日价格区间分位 + 成交量加权均价与当前价偏离
- **数据源**: DuckDB daily_adj.close/vol (最近60日)
- **逻辑**: 价格在筹码密集区上方=支撑强，下方=压力大
- **初始权重**: 0.3

### 1.7 支撑阻力位 [新增] (权重 0.3 → ±0.8)
- **计算**: 识别20/60日最高/最低/密集成交区，当前价与最近SR位距离
- **数据源**: DuckDB daily_adj (最近60日high/low/close)
- **逻辑**: 接近支撑位=做多加分，接近阻力位=做空加分
- **初始权重**: 0.3

## 二、消息面因子 (3因子，维度权重 20%)

### 2.1 个股公告 [新增] (权重 0.8 → ±2.0)
- **计算**: web_search("股票代码 公告 2024") 提取关键事件
- **数据源**: web_search (百度/东方财富公告页)
- **事件评分**:
  - 业绩预增/回购/增持 → +1.0~2.0
  - 业绩预亏/减持/监管函 → -1.0~-2.0
  - 分红/股权激励/重大合同 → +0.5~1.0
  - 无重要事件 → 0
- **缓存**: 当日已查询的标的缓存24h
- **初始权重**: 0.8

### 2.2 行业政策 [新增] (权重 0.5 → ±1.5)
- **计算**: 维护行业政策日历 + web_search("行业名 政策 2024")
- **数据源**: web_search + 固定日历
- **评分逻辑**:
  - 利好政策(补贴/降税/放开) → +1.0~1.5
  - 利空政策(监管/加税/限制) → -1.0~-1.5
  - 行业中性 → 0
- **初始权重**: 0.5

### 2.3 龙虎榜数据 [新增] (权重 0.5 → ±1.5)
- **计算**: web_search("龙虎榜 股票代码") 提取游资/机构动向
- **数据源**: web_search (东方财富龙虎榜)
- **评分逻辑**:
  - 机构净买入>1000万 → +1.0
  - 游资接力(连续上榜) → +0.5
  - 机构净卖出>1000万 → -1.0
  - 未上榜 → 0
- **初始权重**: 0.5

## 三、情绪面因子 (4因子，维度权重 25%)

### 3.1 市场宽度 (权重 0.8 → ±2.0)
- **计算**: `COUNT(pct_chg>0) / COUNT(*)` 全市场(排除ST/BJ)
- **数据源**: DuckDB daily.pct_chg
- **逻辑**: >0.6偏牛情绪，<0.4偏熊情绪
- **初始权重**: 0.8

### 3.2 涨跌停比 [新增] (权重 0.5 → ±1.5)
- **计算**: `涨停家数 / (涨停+跌停家数)` 
- **数据源**: DuckDB daily.pct_chg (≥9.9%=涨停, ≤-9.9%=跌停)
- **逻辑**: 比值>0.8=情绪亢奋(做多加分)，<0.2=恐慌(做空加分)
- **初始权重**: 0.5

### 3.3 北向资金 [新增] (权重 0.5 → ±1.5)
- **计算**: web_search("北向资金 今日净流入") 提取净买入额
- **数据源**: web_search (东方财富/同花顺)
- **逻辑**: 净流入>30亿=外资看多，净流出>30亿=外资看空
- **缓存**: 每日缓存，交易时段每小时刷新
- **初始权重**: 0.5

### 3.4 融资融券 [新增] (权重 0.3 → ±1.0)
- **计算**: web_search("融资余额 变化") 提取融资余额变化
- **数据源**: web_search
- **逻辑**: 融资余额上升=杠杆资金看多，下降=去杠杆/避险
- **初始权重**: 0.3

## 四、宏观面因子 (4因子，维度权重 20%)

### 4.1 美股隔夜-标普500 [新增] (权重 0.8 → ±2.0)
- **计算**: `(SP500今日-昨日)/昨日 * 100`
- **数据源**: web_search("S&P 500 today") 或 新浪美股API
- **逻辑**: A股开盘前(9:00)获取隔夜美股涨跌，正相关约0.3
- **缓存**: 每日9:00刷新，缓存至次日
- **初始权重**: 0.8

### 4.2 美股隔夜-纳斯达克 [新增] (权重 0.5 → ±1.5)
- **计算**: 同上，Nasdaq Composite
- **数据源**: web_search("NASDAQ today")
- **逻辑**: 科技股映射A股科技/创业板
- **初始权重**: 0.5

### 4.3 人民币汇率 [新增] (权重 0.4 → ±1.0)
- **计算**: `USDCNY变化 = 今日-昨日`，贬值→利空A股
- **数据源**: web_search("USDCNY 汇率") 或 新浪外汇
- **逻辑**: 人民币贬值>0.3%=利空，升值>0.3%=利多
- **初始权重**: 0.4

### 4.4 VIX恐慌指数 [新增] (权重 0.5 → ±1.5)
- **计算**: VIX > 25 = 全球恐慌，VIX < 15 = 平静
- **数据源**: web_search("VIX today")
- **逻辑**: VIX>30 → 全球风险偏好降低，A股承压
- **初始权重**: 0.5

## 五、评分汇总

### 5.1 维度内归一化

每个维度内因子得分线性归一化到 -N ~ +N 范围，保证不同维度间可比较：

```
tech_score     = norm(trend + momentum + position + volume + atr + distribution + sr, max=7.0)
news_score     = norm(announcement + policy + dragon_tiger, max=4.0)
sentiment_score = norm(breadth + limit_ratio + northbound + margin, max=5.0)
macro_score    = norm(sp500 + nasdaq + fx + vix, max=5.0)
```

### 5.2 维度加权

```
总分 = tech_score * W_tech + news_score * W_news + sentiment_score * W_sentiment + macro_score * W_macro
```

**初始权重**: W_tech=0.35, W_news=0.20, W_sentiment=0.25, W_macro=0.20

**自适应调整**: 每20日回测各维度独立准确率，Softmax重分配：
- 准确率前三的维度权重+5%
- 准确率最低的维度权重-5%
- 调整幅度限制 ±0.10

### 5.3 市场阶段调整 (regime_detector)

| 市场阶段 | W_tech | W_news | W_sentiment | W_macro |
|---------|--------|--------|-------------|---------|
| 牛市    | 0.40   | 0.15   | 0.20        | 0.25    |
| 熊市    | 0.25   | 0.25   | 0.30        | 0.20    |
| 震荡    | 0.35   | 0.20   | 0.25        | 0.20    |
| 高波动  | 0.20   | 0.30   | 0.30        | 0.20    |

## 六、因子数据源汇总

| 因子 | 数据源 | 更新频率 | 失败回退 |
|------|--------|---------|---------|
| 技术面1-4 | DuckDB日线 | 每日16:30 | 用前一日数据 |
| 技术面5-7 | DuckDB日线(计算) | 盘前计算 | 用保守默认值 |
| 消息面 | web_search | 每标的每日1次 | 上次缓存 |
| 情绪面1-2 | DuckDB日线 | 每日盘后 | 用最后已知值 |
| 情绪面3-4 | web_search | 每日/每小时 | 上次缓存 |
| 宏观面 | web_search | 每日9:00 | 上次缓存(≤48h) |

## 七、因子互斥与去重

- 同一只标的消息面因子24h内只查询一次 (web_search缓存)
- 宏观面因子全市场统一，不逐只计算
- 情绪面3-4全市场统一值，不逐只计算
- factor_snapshots表记录每只标的每因子得分，供回测和权重调整
